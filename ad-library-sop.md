# Meta Ad Library workflow

Tool: https://www.facebook.com/ads/library (United States, active ads)

## Useful

- Creative, hook, offer, CTA, start date, landing page (via click-through)

## Not available

- Spend, CPA, ROAS, Ads Manager targeting

Long run time means the advertiser still pays to keep the ad live; it is not proof of profit.

## Minimum log fields

page, format, hook_3s, offer, proof_type, cta, start_date, observation_date, lp_promise

## Output

Claim map -> test queue -> [competitive log](./appendix/competitive-log-blenders.md) -> [week1 report](./week1-report.md)

Do not copy competitor assets; reuse angle and proof type only.
